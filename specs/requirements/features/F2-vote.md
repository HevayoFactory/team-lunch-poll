# Vote

## Purpose

Lets each teammate cast one vote for their preferred lunch option on an open
poll.

Needs: F1.

## User Stories

- F2.1 As a teammate, I vote for one option on today's open poll.
- F2.2 As a teammate, once I've voted I see that I've voted, but not the
current tally.

## Decisions

- A vote is final once cast; it cannot be changed.
- No live tally is shown while the poll is open — a teammate only sees
whether they've voted, not the counts.
- Voting is anonymous; only vote counts are ever shown, never who voted for
what.
